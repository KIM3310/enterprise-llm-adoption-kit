# Objections and Responses

## "We need enterprise-level security controls"
- This kit demonstrates RBAC, audit logs, redaction, injection defenses, and tool allowlists.

## "We need IdP integration"
- Mock JWT is provided with clear OIDC/SAML swap path.

## "We need evidence of quality and regressions"
- Evals harness supports golden sets, rubric scoring, and baseline diff.

## "We need ops readiness"
- Metrics, usage tracking, rate limiting, and retry/backoff are built in.
